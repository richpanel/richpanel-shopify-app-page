Richpanel — Customer Support
Enable the Richpanel widget on your storefront to power live chat, help center, and self-service support flows.
1
Open your theme editor
Go to Online Store → Themes → Customize in your Shopify admin.
Open Theme Editor
2
Go to App Embeds
Click the App Embeds icon (puzzle-piece) in the left sidebar and search for Richpanel.
3
Toggle on and save
Enable the Richpanel embed and click Save. The widget appears automatically — no API key needed.
Manage your inbox in the Richpanel dashboard

Richpanel Returns — Shop Now
Let customers spend their return credit directly in your store. The SDK intercepts checkout and applies the credit automatically.
1
Create a Cart-scoped API key
In your Returns admin go to Settings → API Keys and create a key with Cart scope. Copy it — you'll need it in step 3.
Create API Key
2
Find your checkout button selector
On your storefront open the browser console and run RPReturn.inspect(), then click your checkout button. Common selectors: #checkout, .checkout-button.
3
Enable the extension in App Embeds
Go to App Embeds and enable Richpanel Returns — Shop Now. Fill in the API Key from step 1 and the Checkout Button Selector from step 2.
Open Theme Editor
4
Save and verify
Click Save. On your storefront run RPReturn.isActive() to confirm the SDK loaded, or RPReturn.testMode() to simulate a live credit session.
Manage returns and policies in the Returns dashboard
